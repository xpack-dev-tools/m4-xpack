# The xPack GNU M4

A standalone, cross-platform (macOS, GNU/Linux) binary
distribution of GNU M4,
intended for reproducible builds.

## Project documentation

For information on how to install and use this project, please refer to the
[project web site](https://xpack-dev-tools.github.io/m4-xpack/).

## Project source

The source code of the current release is available on
[GitHub tag v1.4.19-3.1 tree](https://github.com/xpack-dev-tools/m4-xpack/tree/v1.4.19-3.1).
