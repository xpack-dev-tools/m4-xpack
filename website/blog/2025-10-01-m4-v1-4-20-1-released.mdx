The [xPack GNU M4](https://xpack-dev-tools.github.io/m4-xpack/)
is a standalone cross-platform binary distribution of
[GNU M4](https://www.gnu.org/software/m4/).

There are separate binaries for
**macOS** (x64 and arm64)
and **GNU/Linux** (x64 and arm64).

:::note Raspberry Pi

The main targets for the GNU/Linux Arm
binaries are the **Raspberry Pi** class devices (aarch64 only;
armv6 and armv7l are no longer supported).

:::

## Download

The binary files are available from <a href={frontMatter.download_url}>GitHub Releases</a>.

## Install

The easiest way to install this specific version, is by using **xpm**:

<CodeBlock language="console"> {
`xpm install @xpack-dev-tools/m4@${frontMatter.version}.${frontMatter.npm_subversion} -verbose
`} </CodeBlock>

Comprehensive instructions for installing **xPack GNU M4** on different platforms
can be found in the [Install Guide](/docs/install/).

## Compliance

The **xPack GNU M4** is based on the official
[GNU M4](https://www.gnu.org/software/m4/) sources.

The current version is based on:

- GNU M4 version {frontMatter.m4_version}
from {frontMatter.m4_release_date}.

## Build

The binaries for all supported platforms
(Windows, macOS and GNU/Linux) were built using the
[xPack Build Box (XBB)](https://xpack.github.io/xbb/), a set
of build environments based on slightly older distributions, that should be
compatible with most recent systems.

For the prerequisites and more details on the build procedure, please see the
[Maintainer Info](/docs/maintainer/) page.
